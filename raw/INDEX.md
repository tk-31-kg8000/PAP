# raw/ 索引

本目录存放**外部原始素材**——只读，只进不出。

素材是证据链的起点，**不得修改或删除**；需要引用时，在 `wiki/` 或 `records/` 中写指针而非复制。

---

## 本索引的写法

通则见 `AGENTS.md`（「INDEX 写法通则」）。以下是本目录特有的约定。

- 新增素材时追加一行，**按类别排列**（同类相邻）。
- 「类型」填素材的形态：期刊论文 / 学位论文 / 标准规范 / 数据集 / 图片 …
- 「说明」列**只做定位**——写它讲什么主题，便于日后检索命中即可。
- **不摘录结论、不复述内容、不评价质量**：内容一律以原文为准。
